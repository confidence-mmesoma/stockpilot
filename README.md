# StockPilot

Inventory and sales management system for small retail businesses.

## Tech stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: PostgreSQL with Prisma
- Authentication: bcrypt and JWT (HTTP-only cookies)
- Real-time: Socket.io
